A badge is a short label for status, a count, or a category. It sits next to a heading, inside a table cell, or on a button. It is not a banner — it does not announce a page-level event.

Host is a `span` or `div` with `.k-badge`. A variant sets the color. A style sets the fill: default is solid, then outline, dash, soft, and ghost. Color and style combine, so `k-badge--info k-badge--soft` is a tinted info chip.

Sizes run from `--xs` to `--xl`. Default is 1.5rem. An empty badge — no text, no icon — becomes a dot. Put a kit icon inside when the color alone is not enough.

## Accessibility

A badge is not a live region. Do not put `role="alert"` on it. If the color carries meaning, say it in the text or pair an icon that is hidden from the tree (`aria-hidden="true"`) with a word. Empty dots are decorative; if a dot is the only status, give the badge an `aria-label`.

## Dos and don'ts

**Do**
- Pair a color variant with a style when you want a wash or an outline.
- Keep the label to a word or a short count.
- Use an empty badge as a dot, with an `aria-label` if it is the only status.

**Don't**
- Put `role="alert"` on a badge. That is a [banner](/components/banner/).
- Write a sentence in a badge.
- Rely on color alone.
