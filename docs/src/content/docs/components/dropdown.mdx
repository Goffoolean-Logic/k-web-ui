A dropdown is a short list of choices attached to a trigger — sort order, a row menu, a overflow. It is not a select for a form value; use a native `<select>` for that.

You write the markup: a `.k-dropdown` host, a trigger button, and a hidden `.k-dropdown__menu` of `.k-dropdown__item` buttons or links. `KDropdown.mount` toggles open, closes on outside click, and moves through items with the keyboard. Escape closes. `--end` aligns the menu to the inline end of the host.

The trigger should already look like a button. The kit adds `aria-haspopup` and `aria-expanded`.

## Accessibility

`KDropdown.mount` sets `aria-haspopup="menu"` and `aria-expanded` on the trigger, `role="menu"` on the menu, and `role="menuitem"` on items. Give the menu an `id` so the trigger gets `aria-controls`. Arrow keys open and move; Home / End jump; Escape closes and returns focus to the trigger. The trigger must be a real button.

## Dos and don'ts

**Do**
- Write the host, trigger, and menu yourself, then `mount`.
- Use a real button as the trigger.
- Give the menu an `id` so the trigger gets `aria-controls`.

**Don't**
- Use a dropdown as a form `<select>`.
- Open a [modal](/components/modal/) for a short list of actions.
- Leave the trigger as a `div`.
