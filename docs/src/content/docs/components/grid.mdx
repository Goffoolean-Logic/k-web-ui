A grid is a row of repeating tiles — an icon set, a swatch list, a gallery. It is not a [table](/components/table/). Use a table when the data is rows of the same columns.

Host is `<div class="k-grid">` or `<ul class="k-grid">`. Default columns auto-fill from `8rem`. Pin a count with `--2`, `--3`, `--4`, or `--6`. `--tight` shortens the gap.

Children can be anything. `k-grid__cell` is an optional tile: raised surface, border, centered stack. A `code` caption in the cell picks up muted type.

No kit JS.

## Accessibility

A grid here is layout, not an ARIA grid. Do not set `role="grid"`. Use a `<ul>` when the tiles are a set. Decorative marks stay `aria-hidden`; the name lives in text in the cell.

## Dos and don'ts

**Do**
- Use auto-fill for catalogs. Pin a count only when the row must stay even.
- Use a `<ul>` when the cells are a set.
- Put the name in text. Icons stay `aria-hidden`.

**Don't**
- Use a grid for tabular data. That is a [table](/components/table/).
- Put `role="grid"` on the host.
- Mount kit JS on it. There is none.
