A sidebar is a drawer for nav or filters. The open state is a checkbox. No kit JS. Use it when the panel should overlay the main column, not sit in the document flow.

Host is `.k-sidebar`. Order matters: the hidden checkbox, then the scrim label, then the panel, then main. Labels with `for` matching the checkbox id toggle it — one in main to open, one in the panel to close. The scrim is the same toggle; clicking the dimmed page closes the drawer.

`--end` docks the panel on the inline end. Reduced motion drops the slide.

## Accessibility

The checkbox is the state. Visually hide it with `.k-sidebar__toggle`, do not `display: none` it, or the labels stop working. Triggers are `<label for="…">` so they are operable with a click or the associated input. Put a visible Close in the panel. The scrim is the same toggle. Give the panel a heading or labelled links so the drawer has a name.

## Dos and don'ts

**Do**
- Keep the order: checkbox, scrim, panel, main.
- Match every `for` to the checkbox `id`.
- Put a visible Close in the panel.

**Don't**
- Mount kit JS on it. There is none.
- Hide the checkbox with `display: none`.
- Use a sidebar for content that should stay in the document flow.
