A link is navigation — another page, a hash, an external URL. Use a [button](/components/button/) when the click stays on this page.

Host is an `<a>` with `.k-link`. It uses primary orange and an underline. Hover darkens to the primary hover token.

There is no disabled class. Add `aria-disabled="true"` when the destination is unavailable; the kit removes pointer events and the underline.

## Accessibility

Use a real `<a>` with an `href`. Color is not the only cue — the underline stays. `aria-disabled="true"` removes pointer events and the underline; the link should also be taken out of the tab order or given a reason in the surrounding copy if it must stay visible.

## Dos and don'ts

**Do**
- Use a real `<a>` with an `href`.
- Keep the underline. It is the cue besides color.
- Use a [button](/components/button/) for an action on this page.

**Don't**
- Style a `span` or `div` as a link.
- Drop the underline for a "cleaner" look.
- Use a link as a button.
