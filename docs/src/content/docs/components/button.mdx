Use a button for an action on the current page — save, cancel, delete, open a modal. Navigation belongs on a [link](/components/link/).

The host is a real `<button>` with `.k-btn` and a variant. The variant is the color job: primary is the main action, secondary sits next to it, ghost recedes, accent is ink, danger is destructive. Pair a size modifier when the chrome around it is tight or large. `--block` stretches it to the full width of its parent.

Disabled is the `disabled` attribute (or `aria-disabled="true"`). The kit dims the control and blocks the pointer. Icons inside a button size to `1em` so they follow the type, not the standalone icon scale.

## Accessibility

Use a real `<button>`, not a `div`. The kit focus ring is global for `k-` classes — do not restyle it per variant. Prefer `disabled` when the control must not fire; `aria-disabled="true"` is the same look if you need to keep it in the tab order. Icons inside are decorative — keep `aria-hidden="true"` on them and put the name in the button text, or use `aria-label` on an icon-only button.

## Dos and don'ts

**Do**
- Use a variant. Primary for the main action, secondary next to it, danger for destroy.
- Put the name in the button text. Icons stay `aria-hidden`.
- Use `disabled` when the action cannot run.

**Don't**
- Stack variants (`k-btn--primary k-btn--danger`).
- Use a button to go to another page. That is a [link](/components/link/).
- Restyle the focus ring. It is global.
