The kit ships a small set of marks, not an icon library. Use them for chrome — chevrons, status, close, loading. If you need a product illustration, bring your own SVG.

The host is a `span` with `.k-icon` and a name modifier. The glyph is a CSS mask in `currentColor`. No inline SVG required.

```html
<span class="k-icon k-icon--info" aria-hidden="true"></span>
```

```js
import { createIcon } from 'k-web-components/js';

button.append(createIcon('chevron-left'));
```

Inline `<svg class="k-icon">` still works if you bring your own path.

`k-icon--loading` is orange on the light canvas and white in dark. It does not spin. Wrap it in [Spin](/components/spin/) to rotate it.

## Sizes

| Class | Size |
| --- | --- |
| — | 4rem |
| `k-icon--xs` | 1.5rem |
| `k-icon--sm` | 2.5rem |
| `k-icon--lg` | 7rem |

Inside a `k-btn`, pagination button, or carousel arrow, icons drop to `1em`.
