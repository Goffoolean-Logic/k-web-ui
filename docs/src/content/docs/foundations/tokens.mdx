---
title: Tokens
description: Semantic color and shape tokens, switched with data-theme.
---

Semantic tokens live in `themes.css`. Switch `data-theme` on the root and every `k-` class that references them repaints. Orange chrome (`--k-primary`, `--k-field`, `--k-border`, `--k-ring`) is defined once on `:root` and does not change with the theme.

Dark surfaces come from the steel palette. `--k-palette-steel-950` is black — the canvas. Raised chrome sits on 900, hard on 800.

| Token | Role |
| --- | --- |
| `--k-surface` | Page canvas |
| `--k-surface-raised` | Cards, menus, raised chrome |
| `--k-fg` / `--k-fg-muted` | Ink |
| `--k-border` | Hairlines |
| `--k-primary` / `--k-primary-fg` | Primary actions |
| `--k-accent` / `--k-accent-fg` | Inverse chrome |
| `--k-danger` / `--k-info` / `--k-success` / `--k-warning` | Status |
| `--k-ring` | Focus ring |
| `--k-radius` / `--k-radius-lg` | Corners |

Utilities follow the same names: `bg-k-primary`, `text-k-fg`, `border-k-border`, `rounded-k`. They emit `var(--k-…)` so a theme switch does not need a rebuild.

The focus ring is global for `k-` classes. One definition in the base layer. Do not restyle it per component.
