---
title: Typography
description: Outfit for UI. IBM Plex Mono for code.
---

Outfit is the UI face. IBM Plex Mono is the code face. Both are self-hosted as Latin `.woff2` files.

Every `k-` class gets Outfit. `code`, `kbd`, `samp`, and `pre` inside kit markup get Plex Mono. The page around a component is left alone.

Utilities: `font-k-sans` and `font-k-mono`.
