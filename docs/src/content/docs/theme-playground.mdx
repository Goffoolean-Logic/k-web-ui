The kit is tokens. Change `--k-primary` and every primary button follows. You do not restyle each class.

Pick a token in Colors, or edit the CSS. Copy either way. Paste after the `k-web-ui` import. Put `data-theme="light"`, `dark`, or `auto` on the document root, the same as [Getting started](/getting-started/). The stage below is a sandbox. The rest of the docs keep the kit theme.

See [Colors](/foundations/colors/) for what each token is for, and [Styles](/foundations/styles/) for radius, shadow, and the focus ring.
